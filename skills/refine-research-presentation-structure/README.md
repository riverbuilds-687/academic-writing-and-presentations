# 学术汇报思路优化

一场有说服力的汇报，能让专家从几项成果的联系中看清整项研究推进了什么，从你选择策略的理由中看出你对科学问题的判断。

这套 Skill 适用于科研报奖、成果答辩、专家面试及系列研究汇报。它帮你从四个地方梳理研究思路、打磨关键论证。

[下载 v1.0.2（ZIP）](https://github.com/riverbuilds-687/academic-writing-and-presentations/releases/download/refine-research-presentation-structure-v1.0.2/refine-research-presentation-structure-v1.0.2.zip) · [在 Codex 中使用](#在-codex-中使用)

## 一、成果总览，讲出多项研究的系统性和推进性

围绕共同的科学问题安排成果顺序。几项工作彼此递进，就讲清前一阶段的认识怎样成为下一步研究的台阶。几项工作并列或交叉，就讲清它们各自回答了哪一部分，又怎样相互补充。

## 二、挑战、策略和效果之间，要讲通两层关系

第一层是为什么选择这项策略，要讲清原有研究路径受到了什么限制。第二层是为什么会出现这样的效果，要结合证据，说明策略具体改变了什么。

## 三、每项成果讲到收尾，要从实验结果说到科学贡献

有了这项结果，原来做不到、做不好或说不清的事，现在有了什么改变。突破性能限制、揭示新的规律、厘清原先不明确的作用关系，都可以是这项工作的贡献。

## 四、总结提炼整体贡献，展望交代下一步的依据

回到开头提出的科学问题，讲清几项工作合起来形成了什么新认识，或建立了什么新方法。再从已有发现、方法或仍待解决的问题出发，说明下一步准备往哪里推进，以及为什么选择这个方向。

## 可以从哪些材料开始

还在准备提纲时，可以把研究思路和论文成果交给它，梳理几项工作的联系和讲述顺序。

已有 PPT 初稿时，可以只审一项成果，也可以修改整稿。它会结合页面、图表和已有讲稿，把建议落到具体位置，说明哪些地方已有依据、只需调整讲法，哪些结论还需要补充证据。材料充分时，会给出可直接替换的表述。整稿调整后，还会复查关键论证，确认删改中保留了支撑结论的证据。

## 在 Codex 中使用

1. 下载并解压本页的 ZIP。把完整的 `refine-research-presentation-structure` 文件夹复制到 `~/.agents/skills/`（`~` 表示你的用户主目录）。复制后，文件位置应为 `~/.agents/skills/refine-research-presentation-structure/SKILL.md`。
2. 新开一个 Codex 聊天，附上想讨论的材料。可以从一页 PPT、一段讲稿或一份完整初稿开始。有相关论文、图表或汇报时长要求时，可一并提供。
3. 在消息中输入 `$refine-research-presentation-structure`，接着写明希望它帮你看什么。

> 请用 $refine-research-presentation-structure 帮我看这份答辩 PPT 的成果总览。评委能从这一页看出三项工作共同回答了什么问题吗？请指出该保留什么、哪里需要补一句解释，并给我一版改稿。

如果 Codex 还找不到这个 Skill，可以在聊天中指定已解压的 [SKILL.md](./SKILL.md)，让助手读取后分析你的材料。
