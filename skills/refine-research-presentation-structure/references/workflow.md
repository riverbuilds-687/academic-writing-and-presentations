# 材料与分阶段执行

## 输入处理

从当前对话和文件识别：汇报用途、听众、时间或篇幅、材料类型、成果范围、作者角色、用户本轮需要。能从材料确定的直接使用。用途不明但不影响局部判断时，先完成局部工作并说明采用的场景；会改变主线或科学判断的缺项才问。

| 输入 | 先做什么 | 可以交付什么 |
|---|---|---|
| PPT初稿 | 读取实际页面、顺序、图题坐标和已提供的备注/讲稿；记录解析遗漏 | 定位到页与图的诊断、结构修改、可替换文字；获准且工具可用时另存修改文件 |
| 论文或成果集 | 阅读与主张对应的正文、图表、方法条件，辨认各项工作的科学联系 | 基于已读证据的汇报主线与成果单元；不能仅按摘要和期刊排次序 |
| 研究思路、口述或零散记录 | 区分已完成、正在验证和计划，复述作者已有认识 | 阶段性结构、问题候选、需作者确认的联系；不把设想包装成既有成果 |
| 只有片段文字 | 查看必要前后文，说明实际检查范围 | 局部诊断和改稿；不能宣称整个PPT通过 |

输入含PPT/PDF/Word时使用所在环境的对应读取能力，不在本Skill复制格式解析教程。附件或引用不可访问时，报告缺少的准确文件/页段；只暂停依赖它的判断，其余继续。没有工具读取实际页面时，可完成文字诊断，但页面与视觉可读性检查保留未验收状态。

## 理解记录

简单任务用短注释；多成果或多轮修改才建表。为每项工作提取：研究对象及问题、原路径限制、策略与选择依据、观察及比较条件、解释证据、贡献、与其他工作的关系、定位。

采用以下身份，避免把不同依据混为一谈：

- `原稿事实`：材料实际陈述或展示的内容，记文件与页/图/段；这是来源身份，不宣称已独立证实。
- `作者确认`：用户明确补充或接受的科学判断及改动范围，记确认内容；不冒称论文已写明。
- `AI推断`：根据上述材料提出的结构关系、解释或表述候选，写明推断依据。涉及新机制、研究动机或事实扩展时，不直接进入确定式成稿。
- `待确认`：缺失或冲突信息，指出它会影响哪项主张或改动。

可以同时记录“原稿事实：作者提出假说”，不要把它误读为该假说已证实。原稿自相矛盾、图文不符时保留两处定位，请作者确认；不得凭一个版本更晚就消除冲突。

## 分阶段推进

### A. 结构诊断

先复述当前材料真正表达了什么，再判断与汇报用途是否匹配。输出最重要的结论和需要处理的具体联系。主线未确定时可给有依据的候选及各自依赖，不强选一个好看的框架。

### B. 总览与成果排序

明确总体问题和每项工作承担的研究任务，再选择图式与讲述顺序。每个移动、合并或保留都说明科学原因。可直接交付总览文字、各项成果标题、连接语或图中节点与关系，不止给版式名称。

### C. 单项工作

沿挑战—策略和策略—效果两处关系查证据，补足已有但未呈现的解释，再从结果收束到贡献。对某页有不同做法时，比较保留、压缩、移至讲稿或备份页、删除各自对理解的影响。若只要求审查，交付动作，不越权重写。

### D. 总结、展望与语言

核对总结是否从各项成果升到整体贡献，展望是否从已有基础出发。之后再改主语、动作对象、阶段、条件、对照和回指。保留成熟术语、必要重复和关系清楚的中长句；避免多次换泛称导致对象漂移。

### E. 验收和交接

执行[审查清单](review.md)，交付本轮可用结果。若制作了文件，记录实际交付文件及版本，核对打开/渲染后的页面，不用旧截图替新文件验收。没有制作文件就不声称已修改PPT。

## 异常处理与停止条件

| 异常 | 处理 |
|---|---|
| 总体问题或成果关系材料不足 | 给有依据的候选，问决定关系的最少问题；暂停将候选写为事实，其余可继续 |
| 机制证据缺失 | 保留观察；解释维持原有假说身份或标待确认；明确缺口，不能仅弱化措辞后判通过 |
| 关键数值、单位、样品或比较条件冲突 | 定位冲突，保留不依赖冲突的部分；该结论在确认前不定稿 |
| 文件打不开、文字乱码、图表未解析、仅有截图局部 | 说明实际可读范围，尝试可用读取方式；仍不可读时请用户补相应材料，不假装审完 |
| 用户指定保护内容、只改一页或只审不改 | 在范围内诊断；若跨页关系影响结论，指出依赖，不自行扩大改动 |
| 时长不足 | 按科学主线保留决定理解的证据，把次要展开移入讲稿/备份；删后复读整体，不靠不断缩字 |
| 新反馈与此前确认冲突 | 以最新明确决定为准并记录受影响处；不把一次局部偏好泛化为永远适用的规则 |
| 一轮修改后仍是同一证据缺口 | 停止措辞循环，指出缺哪份材料或哪项作者判断；交付已完成部分和有条件版本 |

## 迭代记录

每轮只追踪会影响决定的内容：版本/日期、本轮范围、依据、改动、未决项、复查结果。先判断反馈属于执行遗漏、任务判断、证据新增还是新规则，再修对应位置。已经通过且未受影响的部分保留；新的修改影响总览、机制或总结时，复查对应上下游，不反复重跑无关检查。
