# 四项判断与修改方法

## 1. 成果总览：让评委理解整项研究

先从作者材料提炼总体科学问题，保留具体研究对象、关键限制和要认识或实现的事情。“高效催化”“先进材料”“服务国家需求”等可以交代背景，单独使用不足以说明各项工作的科学联系。只有题目时可给问题表述候选并标为AI推断，请作者确认，不替作者决定研究内核。

为每项成果辨认三个落点：针对共同问题中的哪一层；形成了什么认识或能力；它与其他成果如何相接。成果顺序服务认识推进，论文期刊、影响力和发表先后不能代替这一判断。实际依赖关系和真实历史分开：可以重组讲述顺序，不能倒造开展研究时的动机或先后。

| 材料支持的关系 | 总览形式 | 必须讲清的内容 | 修改动作 |
|---|---|---|---|
| 并列：同一问题下解决不同限制 | 三项时可用三列式；项数不同按实际分支 | 总体问题、各项分工、共同形成的认识或能力 | 把“论文一/二/三”换成各项解决的科学问题或贡献；不加虚假递进箭头 |
| 递进：前项认识/能力构成后项依据 | 递进式 | 前项获得什么、还限制什么、后项据此改变什么 | 在两项工作之间写出认识变化或策略转向，箭头标明承接含义 |
| 交叉：共享方法、证据互补、共同支持结论等 | 关联框架图 | 共同核心、各项关系及关系依据 | 用带含义的连线标出共享、支撑或反馈；不能用无标签箭头暗示因果 |

混合关系可采用局部并列、整体递进；不为图形整齐改造科学事实。总览的主问题和核心关系必须在总览论述单元中可见；后文可展开证据，不能直到结尾才让听众猜出主题。

判断是否达到目的：评委能否说出“研究者围绕什么问题持续推进、各阶段认识怎样深化”。有真实递进时，要能说明每项工作怎样建立在前一阶段认识之上，怎样成为下一步的台阶；并列工作则解释为什么必须同时处理这些方面。不能只把几篇论文换成统一颜色就称系统性。

## 2. 挑战—策略—效果：解释两处联系

分析时可用下面的关系串寻找缺口，它不要求每页都写成六个框：

`原路径及具体限制 → 策略选择的科学理由 → 改变的对象/状态 → 影响的过程 → 观察效果 → 贡献`

第一处联系是“为什么选它”。例如材料已说明某设计减少某类位点流失，就要让听众理解流失怎样限制原路径、该设计针对哪个环节。是否进一步解释流失本身的原因，由当前主张需要决定。只说“稳定性差，所以设计新材料”仍未说明选择理由。

第二处联系是“为什么有效”。说明策略改变了什么，改变如何作用于当前讨论的过程，又怎样带来观察结果。仅解释“某过程有利于性能”，仍可能缺少“当前设计为何改变该过程”。比较两个方案时，两者共有的机制不能单独解释效果差异；应找已提供的作用程度、方式或条件差别。

逐项辨别：

- **设计意图：**作者希望用策略改变什么；预期不能冒充已验证的结果。
- **观察：**实验或计算实际显示了什么；数字须保持样品、条件、单位、比较对象和来源一致。
- **解释：**哪些证据支持哪一步作用；区分相关、模型预测、推断与直接测得。
- **未知：**当前确实缺哪条关系的依据。给出具体缺口和作者可补的材料，不擅自安排整套新实验。

已有依据未写清：从原图、正文或已提供讲稿补回必要关系，并核对是否改变主张。材料没有答案：保留真实结果，把解释标为作者假说或待确认；不要自行发明一个常见机制填空，也不要把整项成果判成无价值。

“支持”改成“可能支持”只能调整确定程度，不能解释作用对象和过程。相反，原材料已充分支持的结论，不为了显得谨慎一律改成“可能”。纯结果页或明确的进展讨论可以保留尚未解决的问题，因果解释可由连续数页共同完成。

## 3. 单项成果：结果之后要回答贡献

先保留足以成立的结果，再问：相对什么已有能力或认识，哪件原来做不到、做不好、说不清的事发生了改变？

| 贡献类型 | 应讲清的变化 | 对应依据 |
|---|---|---|
| 性能或能力 | 哪个指标/任务在何条件下改善，改善解决什么限制 | 可比基准、幅度及必要条件 |
| 新规律 | 发现了哪些对象或变量之间怎样的关系，在哪个范围成立 | 系列比较、规律适用范围及例外（若材料提供） |
| 作用关系 | 原来混在一起或未明确的影响，现在如何区分或解释 | 对照、表征、模型与解释的匹配 |
| 方法或策略 | 新增何种可实施的控制、识别、设计或预测能力 | 方法用途、验证及边界 |

不要求一项成果占满四类，也不把“揭示机制”当贡献升级词。没有支持机制的证据时，准确呈现已经成立的观察或规律。论文档次、引用次数、奖项和“国际领先”不替代科学贡献；确需展示外部评价时与科学论证分开。

建议落到原页：例如“保留这组对照及性能变化；在结果后增加材料已支持的能力改变，并注明它解决的是原路径的哪个限制”。若不知道比较条件，就指出缺少哪一个条件，不先写“显著提升”。涉及个人贡献，沿用作者提供的角色说明，不把团队成果改成个人独立完成。

## 4. 总结与展望：增加认识，不重列成果

总览负责建立研究地图，总结负责收束整项研究的贡献。用总体科学问题检验：几项工作合起来，使研究者能解释、区分、控制或实现什么？可以是共同建立一项认识，也可以是几个互补方面的进展；不为了总结造一个无材料支持的统一机制。

总结保留关键对象和作用关系，不能压成“建立体系、突破瓶颈、提供支撑”等泛词。不要再按论文顺序重复方法和最佳性能；如某数字是整体贡献成立的关键边界，可保留。

展望从当前研究出发，按材料选用以下方向：

- **深化已有研究：**已有规律在哪个层次还可深入，研究深化会增加什么认识。
- **拓展研究范围：**现有能力能否拓展到新的对象、条件或尺度，为什么这个拓展有价值。
- **提出新策略：**哪些已获得的认识使新的设计或方法值得尝试；明确这是计划。
- **延伸实际应用：**如何把已验证能力推进到使用场景，现阶段还需要跨越哪些已知条件。

每个方向至少说明“从什么已有基础出发，准备推进什么，为什么有意义”。只列材料支持且本次有用的方向，不为了完整性加“AI赋能、产业落地”，也不把未来预期当既有成果。研究计划型汇报可展开实施安排；成果答辩通常保留目标、关键认识与必要困难即可。
