# 审查清单与质量门槛

## 独立审查顺序

完整汇报、重要重组及正式交稿前，用独立审查者复查；有协作能力时委派独立代理。提供实际稿件、原始依据、用途、必要上下文、用户真实要求和保护范围，不提供写作者的自评、预期答案或“应通过”的暗示。审查者先复述实际理解，再判断本单元应回答什么，最后核对修改任务。独立意见也要根据证据取舍，不能自动全部采纳。

没有独立代理时，另作一次不沿用写作者结论的复读，并说明未完成独立审查；不能冒称多人验证。局部改字不强制启用全套流程。

每个关键论述单元记录实际理解状态：**明确呈现 / 上下文足够 / 无法回答**。PPT区分**页面已呈现 / 已提供讲稿交代 / 尚未交代**。图上画了箭头只是呈现关系，不是科学证据。连续页面已有充分解释时，不要求每页重复。

## 完整检查清单

完整汇报逐组检查；局部任务标明适用项与未检查范围。不得只凭关键词命中打勾，需能够定位依据或复述答案。

### A. 范围、材料与身份

- [ ] 任务、受众、成果范围和本轮允许改动范围已明确；未知部分未被擅自设定为事实。
- [ ] 已指定实际读取版本与页段；原文件只读，输出与原稿分开。
- [ ] PPT实际页面和已有讲稿已读；缺失时准确限定检查范围。
- [ ] 原稿事实、作者确认、AI推断和待确认项能区分；原稿中的假说仍保留假说身份。
- [ ] 亲改保护仅适用于用户已确认范围；老师未改处未被自动判通过。

### B. 总览与系统性

- [ ] 总体科学问题具体到本项研究，而非只剩宏大背景或领域名称。
- [ ] 每项成果在共同问题下的分工、贡献和相互关系可以说清。
- [ ] 排序按研究思路与认识推进，而非按期刊档次或指标大小。
- [ ] 并列、递进、交叉关系有依据；框架图准确表达关系，不靠无标签箭头暗示虚假因果。
- [ ] 真实递进处说明前一阶段认识如何成为下一步台阶；讲述顺序未被写成未经提供的研究历史。
- [ ] 总览让听众理解研究者有意识地持续推进，而不只是展示统一包装的论文列表。

### C. 挑战、策略与效果

- [ ] 原路径的具体限制明确，且该限制确实与所选策略有关。
- [ ] 策略选择理由可从材料理解；“为此、因此、创新地”没有替代科学解释。
- [ ] 能说明策略改变的对象、状态或条件，以及这些变化对过程的影响。
- [ ] 能说明上述变化如何带来效果；仅有共同机制时未据此解释两个方案的差异。
- [ ] 对象、阶段、动作、空间关系与回指正确，没有把前驱体、活性状态或中间体混为一谈。
- [ ] 设计意图、观察、解释和未知分别呈现；语气弱化未被当作补齐逻辑。
- [ ] 纯结果或进展讨论的任务被合理对待；不强迫没有依据的完整机制。

### D. 证据与单项贡献

- [ ] 核心数字、单位、样品、指标定义、条件及比较对象与材料一致。
- [ ] 图、数据、案例分别在支持效果、解释、边界或承接，未仅因已有素材而保留。
- [ ] 每项成果说明原来做不到、做不好或说不清的事情发生了什么变化。
- [ ] 新规律与作用关系被承认为可能的贡献，没有强制写成性能突破。
- [ ] 贡献的范围与证据匹配，没有新增“首次、普适、独立完成、机制证明”等未经支持的主张。
- [ ] 论文归属、团队与个人贡献准确；外部评价没有替代科学论证。

### E. 总结、展望与全局一致

- [ ] 总结回到总体科学问题，提炼整体贡献，并保留必要的具体对象和作用。
- [ ] 总结比总览多一层认识，未只是重列论文与最佳值。
- [ ] 展望与已有基础相接；可选择深化、拓展、新策略或应用延伸，未被限制成问题清单。
- [ ] 展望中的方向、预期与已完成成果区分，没有硬塞AI、应用或统一机制。
- [ ] 总览承诺、各项结果、贡献和总结相互一致，修改一处后已复查受影响处。

### F. 表达、取舍与动作

- [ ] 诊断有原句、页图或缺失关系的真实定位，没有假设原稿错误。
- [ ] 每条必须修改的意见都说明理解上的影响和可执行动作；获准改稿且材料足够时给可替换内容。
- [ ] 先给结论，再给有因果关系的动作；未用空泛“优化逻辑”替代具体建议。
- [ ] 保留原意与有依据的结论强度；成熟术语、必要重复和专业信息没有被过度压缩。
- [ ] 主体、动作、对象、条件、阶段和对照清楚；内容有依据与句子自然分别检查。
- [ ] 已比较保留、压缩、移动和删除对理解的影响；累积删减后仍有足够证据。
- [ ] 没有为了显得严格而制造问题；合理保留与可选调整明确区分。
- [ ] 审查记录没有挤入正文或PPT页面；正文只保留当前主张必需的限定。

## 意见分级与闭合

| 级别 | 定义 | 处理 |
|---|---|---|
| 必须处理 | 影响科学主张、研究关系或本次主要理解 | 修改或获得明确确认后重读；仍未解决时不得称该范围定稿 |
| 确缺资料 | 关键事实或关系当前无法判断 | 指出准确材料/信息及影响；暂停依赖该项的确定性结论 |
| 可选调整 | 不影响主张成立，但可改善表达或时间分配 | 说明收益，由当前任务决定是否采用；不阻止本轮结束 |
| 合理保留 | 原有内容已经准确、必要且位置合适 | 保留并避免下一轮无故重开 |

问题记录至少包括：位置或真实前后锚点、原稿实际表达、依据身份、问题及影响、动作、复查状态。无原句的缺失关系用真实前后页或段定位，不编写“原文”。

修改后审查者重新复述原先无法回答的内容；仅确认“加了一句”不算闭合。拒绝一条审查建议时记录其不适用的具体依据，不把建议数量当完成度。

## 质量门槛

| 门槛 | 通过条件 | 未达到时 |
|---|---|---|
| 理解 | 总体问题、单项任务和真实关系可由材料说明 | 交付结构候选或局部判断，列出影响主线的缺项 |
| 逻辑 | 承担解释任务的单元能讲通两处联系；未知被准确界定 | 补回已有依据，或保留未知并限制结论，不能靠修辞通过 |
| 依据 | 新增科学内容可追溯，身份与确定程度正确 | 撤回无依据新增；待确认内容不进入确定式成稿 |
| 修改 | 意见定位清楚、动作具体，原意和必要证据保留 | 将泛泛意见改为具体文字、关系或材料动作 |
| 验收 | 修改后的实际版本已复读，关键问题闭合，覆盖范围明确 | 说明未验收范围及原因，不宣称整套定稿 |

最终分别报告**结构与任务、科学逻辑与证据、具体语言、检查覆盖**的结果。总体状态使用：

- **本轮范围通过：**该范围的必须处理项已闭合，必要材料已检查；仍可有可选建议。
- **有条件可用：**已知结果及局部表达可用，某些关系/页面仍待确认；明确使用边界。
- **尚不能定稿：**总体问题、核心因果、关键数值或归属仍有影响主要结论的缺口。

格式校验只能检验文件与记录，不证明科学内容正确。不得以“检查项全部填完”或“程序通过”代替上述判断，也不能保证导师或评委不再提出修改。
